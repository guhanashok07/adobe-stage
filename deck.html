02 / The Problem

The Prompt Wall: Breaking Creative Flow

Generative AI tools produce a first draft quickly, but refining details through text prompts is slow and frustrating.

The Last 10% Problem

A prompt gets you 90% of a screen layout. But adjusting spacing, button colors, or typography requires endless follow-up prompts that often break previous edits.

> "Make the CTA slightly darker blue and move it right."
AI regenerates the entire screen and changes layout fonts.

Cognitive Friction (System 1 vs. System 2)

Spatial thinkers work best using direct visual feedback (System 1). Forcing users to describe spatial layout adjustments through text creates unnecessary cognitive effort (System 2).

Core Need: Prompt the initial layout; polish with direct clicks, drags, and sliders.
03 / The Product

Adobe Stage: AI Speed + Direct Visual Control

A browser canvas where generative AI creates editable elements instead of static code blocks.

01
Prompt Generation

Generate initial app dashboards or graphics using plain English prompts.

02
Interactive Blocks

Every output element is an inspectable, drag-and-drop block on the canvas.

03
Direct Visual Sliders

Adjust spacing, colors, and text directly without sending another prompt.

04
Brand Guidelines

Enforce consistent color palettes and typography rules across all generations.
